# M01-03 — Primera prueba unitaria

Una función de descuentos por importe (`src/descuentos.js`) y su fichero de pruebas con Vitest
(`pruebas/descuentos.test.js`), que solo trae la primera prueba. Escribes el resto, encuentras
el error de límites de la función y lo corriges.

Página del laboratorio: [Lab — Primera prueba unitaria](../../labs/M01-introduccion-automatizacion/03-lab-primera-prueba-unitaria.md)

```bash
cd ejercicios/M01-03-primera-prueba-unitaria
# Ejecuta las pruebas unitarias
npx vitest run
```

`solucion/` es el ejercicio terminado (función corregida, pruebas completas y el tramo del reto):

```bash
npx vitest run --root solucion
```
